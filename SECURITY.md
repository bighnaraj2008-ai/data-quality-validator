# Security Policy

## Supported Versions

We provide security updates and patches for the following versions:

| Version | Supported          |
|:--------|:-------------------|
| 0.2.x   | :white_check_mark: |
| 0.1.x   | :x:                |

---

## Reporting a Vulnerability

If you discover a security vulnerability within `data-quality-validator`, please report it responsibly:

1. **Do not create public GitHub issues** for security disclosures.
2. Email details of the issue directly to the project maintainers or utilize GitHub's Private Vulnerability Reporting feature.
3. Provide step-by-step reproduction instructions or a minimal proof of concept.

We appreciate your cooperation in keeping data pipelines and sensitive metadata secure.
